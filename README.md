## Session 01

**Le Travail Change**  
*De l'utilisateur d'IA à l'architecte d'un système intelligent.*

The first experience is being built as an interactive HTML/CSS/JavaScript presentation rather than a conventional slide deck.

## Principles

- Immersion before information.
- One strong idea per screen.
- Frequent audience interaction.
- Demonstration over generic explanation.
- Practical experimentation.
- Human judgment remains central.
- No unnecessary framework complexity.
